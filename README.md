# astrbot_plugin_ignore_user — 不回复名单（用户消息拦截）

让 AstrBot 机器人**不再回复指定用户**的插件。

把某个用户的 ID（QQ 号）加入拦截名单后，他发送的任何消息都会在进入 AI 处理流程之前被直接拦截：私聊不回、群里 @ 不回、指令也不执行。名单在 AstrBot 管理面板的插件配置页里直接增删，**不需要改代码、不需要翻文件**。

## 功能

- 按发送者 ID 精准拦截，命中即终止该消息事件（`stop_event`），不进入 LLM、不触发任何指令与其它插件逻辑
- 覆盖私聊与群聊
- 名单通过插件配置页可视化维护，保存后生效
- 可选的拦截日志：每次拦截在 AstrBot 日志中记一条 `blocked message from <ID>`
- 零依赖、不联网、不收集任何数据；名单只保存在本地插件配置文件中

## 安装

任选其一：

1. **插件市场**：在 AstrBot 管理面板 → 插件 → 插件市场，搜索「不回复名单」或 `astrbot_plugin_ignore_user`，点击安装。
2. **仓库 URL 安装**：在 AstrBot 管理面板 → 插件 → 右下角「+」→ 通过 URL 安装，填入本仓库地址：
   `https://github.com/bhdhdjdjzjizi-arch/astrbot_plugin_ignore_user`
3. **手动安装**：把本仓库克隆/解压到 AstrBot 的 `data/plugins/` 目录下（文件夹名保持 `astrbot_plugin_ignore_user`），然后在插件页重载插件或重启 AstrBot。

要求：AstrBot `>= 4.16, < 5`。

## 配置

安装后打开插件的**配置页**（插件卡片上的齿轮/配置按钮），可看到：

| 配置项 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| 拦截名单（用户 ID / QQ 号）`blocked_qq` | 列表 | 空 | 名单中的用户发来的任何消息都会被拦截，机器人不予回复。在此直接添加/删除 ID，保存后生效 |
| 记录拦截日志 `enable_block_log` | 开关 | 开 | 开启后每次拦截都会在日志中记录一条 INFO 日志（仅含被拦截者的 ID） |

配置文件实体位于 `data/config/astrbot_plugin_ignore_user_config.json`，也可以直接编辑该文件（改后需重载插件或重启 AstrBot）。

## 使用方法

1. 打开插件配置页。
2. 在「拦截名单」中添加要屏蔽的用户 ID，例如 `123456789`（一行一个条目，用面板的列表编辑器添加）。
3. 保存。对方再发消息时，机器人将保持沉默。
4. 想解除时，把对应条目从名单中删掉并保存即可。

## 效果范围

**会拦截的**（名单内用户发出的）：
- 私聊消息
- 群聊中 @ 机器人、或以任何方式触发机器人的消息
- 指令（以 `/` 开头的命令同样不会执行）

**不会拦截的**：
- 其他人的消息，一切照常
- 机器人在群里的主动回复（由群会话触发，不针对任何个人）；名单用户只是得不到针对他本人的回复
- QQ 本身的好友/群关系不受影响——这不是 QQ 拉黑，对方仍能正常发消息，只是机器人不理会

## 工作原理

插件以最高优先级（`priority=1000`）注册了一个监听全部消息事件的处理器。每条消息进来时先比对发送者 ID：命中名单则调用 `event.stop_event()` 中止事件，使其不进入后续管线（包括 LLM 请求）。名单在每次事件时实时读取插件配置，因此在配置页保存后即刻生效。
